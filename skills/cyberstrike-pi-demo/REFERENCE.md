# API / reference (example)

## HTTP `/api/skills/{id}`

- `resource_path`: an in-package relative path, e.g. `FORMS.md`, `scripts/payloads.txt`.
- `depth=summary`: only the summary and table of contents, suitable for first-round retrieval.

## Multi-agent runtime

- Use the Pi **`skill`** tool to progressively load skill packages; optionally enable `multi_agent.skills.filesystem_tools` to access files in the package.
