## No-Limits Principle

```
OODA / the project-blackboard Fact / the iron rule of verification / combined-technique play apply to all security domains. The skill is a framework, not a cage:
  Search everything (multiple channels) · verify everything (a search result ≠ a vulnerability) · chain everything (small vulnerabilities combine into a big breakthrough) · record everything (a negative result is also a Fact)
  No ceiling (Web/APK/EXE/internal network/cloud/firmware/blockchain/AI/wireless/hardware/social engineering all allowed) · when blocked, switch routes · don't stop until the goal is reached
> Given a set of capabilities and a target, derive an attack chain unique to that target, like solving a puzzle——
> This chain may apply to only this one target in the whole world and can never be found online, because you derived it on the spot.
> This is what truly thinking outside the box means.
```
